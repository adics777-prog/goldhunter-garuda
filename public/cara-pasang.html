🛡️ Diblokir Windows Defender / antivirus?

Installer berisi skrip pemasang sehingga sebagian antivirus menahannya. Itu alarm palsu untuk file dari member area Anda sendiri.

  1. Browser: pilih Keep / Keep anyway.
  2. Dihapus Windows Security? Buka Windows Security → Virus & threat protection → Protection history, pilih item GOLD HUNTER GARUDA → Actions → Allow (atau Restore), lalu unduh ulang.
  3. Opsional: tambahkan C:\GOLD HUNTER GARUDA di Virus & threat protection settings → Exclusions.

🌐 WebRequest (laporan ke web)

EA melaporkan hasilnya ke goldhuntergaruda.com (member area, sharing profit). Installer menyalakan WebRequest. Bila tab Experts masih menulis WebRequest tidak diizinkan:

  1. MetaTrader 5: Tools → Options → Expert Advisors.
  2. Centang Allow WebRequest for listed URL dan tambahkan https://goldhuntergaruda.com.
  3. OK, lalu lepas dan pasang lagi EA di chart (atau restart MetaTrader).

🧩 Beberapa setup sekaligus

Satu lisensi = satu nomor akun, chart sebanyak apa pun. Beri setiap chart magic number sendiri (input 1.1) dan nama (1.3): tiap chart menjadi setup terpisah dengan basket dan hasilnya sendiri. Dua chart dengan magic sama berbagi posisi, jadi selalu ganti.

🖥️ PC baru atau pindah VPS

  1. Di VPS baru: pasang MetaTrader 5, login akun yang sama (Save password).
  2. Jalankan installer yang sama dari C:\GOLD HUNTER GARUDA. Backup setup chart terakhir Anda dipulihkan ke MetaTrader yang belum berisi chart GOLD HUNTER GARUDA.
  3. Matikan VPS lama atau tutup MetaTrader di sana, supaya setup yang sama tidak trading dua kali.
FAQ pemasangan

Pertanyaan Umum

Apakah perlu VPS?

EA hanya bertrading selama MetaTrader berjalan. PC yang selalu menyala bisa; VPS Windows lebih mudah karena jalan 24 jam. Paket VPS ada di halaman Harga.

Apakah update mengubah setting saya?

Tidak. Update hanya mengganti file EA dan preset. Chart, input dan profil Anda tetap seperti semula.

Beberapa akun di satu VPS?

Bisa. Jalankan installer tiap akun berlisensi dari folder yang sama C:\GOLD HUNTER GARUDA; satu agen mengurus semuanya.

Installer bilang MetaTrader belum login

Buka MetaTrader 5, login akun berlisensi dengan password trading dan Save password, lalu jalankan installer lagi.

Panel EA bilang lisensi salah

File EA hanya berjalan di nomor akun lisensinya. Pastikan MetaTrader chart itu login di akun tersebut. Ganti akun? Ajukan ganti nomor akun di member area.

Bisa pasang manual?

Bisa: unduh .ex5 dari member area dan salin ke File → Open Data Folder → MQL5 → Experts. Tanpa installer, update tidak otomatis.
