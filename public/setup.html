🎯 Setup rekomendasi

Satu EA, Setup per Pair

GOLD HUNTER GARUDA adalah satu EA. Yang berbeda per pair adalah setup-nya: modal per 0,01 lot, jarak layer, target dan pengaman. Pusat menyiapkan preset rekomendasi untuk tiap pair dan menyesuaikannya dengan setiap versi EA.

Cara memakai preset

Muat dalam Tiga Klik

  1. Buka chart pair-nya

    Di MetaTrader 5 buka chart pair tersebut (M1 cukup), seret GOLD HUNTER GARUDA dari Navigator ke chart.

  2. Muat preset

    Di tab Inputs klik Load lalu pilih presetnya. Installer sudah menyalin semua preset rekomendasi ke MQL5\Presets, jadi langsung ada di daftar.

  3. Izinkan Algo Trading

    Centang Allow Algo Trading, klik OK dan pastikan tombol Algo Trading di toolbar berwarna hijau.

  4. Cek panelnya

    Panel di chart menampilkan setup, lisensi dan layer berikutnya. Hasilnya tampil di member area Anda.

🧩 Setup sendiri

Buat Sendiri, Bandingkan

Setiap chart dengan magic number sendiri adalah setup terpisah: basket sendiri, kantong sendiri, hasil sendiri. Mulai dari preset rekomendasi, ubah satu hal setiap kali, dan biarkan angkanya yang memutuskan.

  • Magic berbeda tiap chart (input 1.1) dan nama singkat (1.3), misalnya XAU 2
  • Beberapa setup di satu akun? Beri tiap setup anggaran (4.0) supaya lot mengikuti bagiannya sendiri
  • Tuas terpenting: modal per 0,01 lot (4.3), jarak layer (5.1), TP (6.1), mode berita (10.1)
  • Simpan input Anda dengan Save sebagai .set baru; update tidak pernah menimpa input chart Anda
